## 权威装载语义（从宿主二进制内读出的 loader 源码，非猜测）

- 发现目录 = 项目根下 `plugin/` 与 `plugins/` 双扫（`DA=["plugin","plugins"]`）；条目 = `.ts/.js` 文件或目录（含 symlink 解引用）。
- 目录条目经 `$$({directory})` 解析出 **`f.server`** 入口；`if(!f.server) return []`（静默）；server 解析结果必须落在该目录内否则静默丢。⇒ **V2 package 路由读 `./server` 导出子路径**——border 现有 exports（"."=CLI、"./server"=plugin/border.ts）形状正确，**R1 不需要**。
- 配置 `plugins:[{package:...}]` 与 V1 `plugin:[...]` 都规范化；相对路径按配置文件目录解析；支持 `file://`。
- **懒激活**：POST `/api/plugin/await-activation` 之前 `/api/plugin` 显示 `data:[]`——在场但空列表是**正常态**；探针断言序必须先激活（V2 版静默坑，0.5.1 教训的镜像）。
