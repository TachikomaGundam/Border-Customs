## 5. Design decisions / interpretations (plan-faithful, stated where the plan left latitude)
- base semantics: "newest remote-tracking tip" = for-each-ref --sort=-committerdate over
  refs/remotes/<name>/ for every configured remote whose sanitized URL ∈ exposureSet (HEAD-ref
  refs excluded). First-push/no-remote ⇒ FULL-TREE diff from the empty tree
  (git hash-object -t tree --stdin), stated in bundle base.mode='full-tree' + base.note —
  chosen over "diff from root commit" so the root commit's own content is reviewable too.
- Patch masking needs the RAW secret values, which the ledger deliberately never stores.
  Resolution: llm-request re-detects over the patch text itself with the deterministic engine
  (scanTree against a throwaway .border/llm-mask-* sandbox, chunks ≤ 8MiB so gitleaks'
  10MiB per-file guard never skips an input), registering hits into TextSanitizer; sanitize()
  replaces them with exactly [REDACTED:<sha256[:8]>], i.e. the same token a deterministic
  finding's valueDigest predicts. Masking therefore covers precisely "values the deterministic
  engines already flag" — the round-2 M9a boundary is quoted verbatim in bundle.dataBoundary,
  in SKILL.md, and in tests. If gitleaks cannot run, llm-request fails closed (exit 2) instead
  of shipping unmasked patches.
- ingest computes valueDigest for agent findings as sha256(stableStringify({rule,target,path,
  line,commit,message,snippet})) — no raw-secret concept for agent findings, but the C1 schema
  + every renderer's sanitizer registration stay satisfied. engine is force-overwritten to
  'agent'; a supplied engine/valueDigest key is tolerated-but-ignored per plan ("Findings minus
  valueDigest — ingester computes"); any OTHER unknown key is rejected with its index.
- llm:true records keep the todo-14 separation: lookupSkipRecord requires record.llm === query
  .llm, verified by the two-directional no-skip-riding test + e2e.
- Prompt template: rulesHash consumes assets/prompts/llm-review.md (commit ca1eb98); template
  edit ⇒ invalidates cached PASS (proven hermetically via BORDER_PROMPT_TEMPLATE_PATH). The
  esbuild dist bundle cannot see repo assets yet — MISSING_TEMPLATE path exits 2 fail-closed,
  consistent with GITLEAKS_VENDORED_CONFIG handling; packaging fix is owned by todos 20/21
  (documented in code + SKILL.md).
- src/cli.ts / src/commands/index.ts untouched; only the two handler bodies replaced
  (exported names runLlmRequest/runLlmIngest preserved).
