## Contract decisions
- validateFinding enforces NO rule-charset regex (only: severity enum,
  valueDigest /^[0-9a-f]{64}$/, path/commit string, line integer, rest
  strings). trufflehog rules are still normalized to `trufflehog/<lowercase-dash-slug>`
  ("Private Key" -> trufflehog/private-key); DEGRADED-ENGINE kept uppercase
  exactly per plan text — legal under the actual validator.
- Missing/broken/failing probe (EngineMissingError|EngineRunError) => one
  CRITICAL finding rule=DEGRADED-ENGINE, engine=<missing engine>, message
  contains verbatim "run border's engine provisioning or install manually";
  result.degraded=true (flag todo 14 rides for ledger-write prohibition);
  CLI must exit 2 regardless of findings.
- Unparseable version string (no /\d+\.\d+(\.\d+)?/ in probe output) =>
  EnginePolicyError {exitCode:2} naming the engine — hard error, NOT a
  degraded finding; border never assumes an unknown engine is current.
- Unknown names in engines.require / --require-engine override =>
  DEGRADED-ENGINE (cannot-probe == cannot-trust).
- secretlint probe = secretlintVersionFingerprint({lockPath?}) (in-process,
  no --version); lock lacking @secretlint/* family => DEGRADED-ENGINE.
- trufflehog probed ONLY when cfg.engines.trufflehog:true (or explicitly in
  the required set); enabled-but-absent == missing required engine.
- engineVersions: extracted semver for gitleaks/trufflehog, sha256 lock
  fingerprint for secretlint — direct computeRulesHash input.
- Empty Raw in a result line => EngineRunError (fail closed; no invented digest).
